# Nexor 0.2.6 — instalação

Requer Windows 10 ou superior x64. As publicações são self-contained.

- `dist/0.2.6/onefile/Nexor-v0.2.6.exe`: edição oficial one-file.
- `dist/0.2.6/trial/Nexor-Trial-v0.2.6.exe`: Trial de 30 dias.
- `dist/0.2.6/installable/`: publicação completa para instalação manual.
- `dist/0.2.6/installer/Nexor-Setup-v0.2.6.exe`: instalador.

Dados locais: `%LOCALAPPDATA%/Nexor`.
